Living Archives v5.7 — Agent Identity Synchronization
=====================================================

Normal visitor-mode identity is synchronized from ElevenLabs' successful
transfer_to_agent system-tool event.

Do not configure syncActiveAgent or setActiveAgent for normal operation.
The app contains no-op compatibility handlers only so older agent configs do
not crash before those tools are removed.

See ELEVENLABS-TRANSFER-SETUP.txt for the current visitor-agent configuration.
