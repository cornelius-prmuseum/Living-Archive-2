PRMUSEUM MULTI-AGENT SETUP
==========================

AVAILABLE UI SLUGS
------------------
Edward Bernays = bernays
Ivy Lee = ivy-lee
Walter Lippmann = lippmann
Arthur W. Page = arthur-page

IMPORTANT UI-SYNC DESIGN
------------------------
The browser does not guess who is speaking after an ElevenLabs transfer.
ElevenLabs preserves the transcript across transfers, but transcript messages do not expose an agent_id.
Therefore the RECEIVING agent must identify itself to the webpage using the client tool below.

This is especially important for a spoken or typed request such as:
"Let me speak with Arthur Page."

The old agent should perform transfer_to_agent. The receiving Arthur Page agent should then call
setActiveAgent with agent_slug="arthur-page" before its first substantive spoken response.
Only then does the main portrait/name change.

1. CREATE THIS CLIENT TOOL ON EVERY AGENT
------------------------------------------
Tool type: Client
Name (case-sensitive): setActiveAgent

Description:
Update the PRMuseum webpage so it displays the historical figure who is actually
currently on the line. Call this when this agent becomes active, especially after
receiving a transferred conversation. This tool only synchronizes the webpage.

Parameter:
Identifier: agent_slug
Type: String
Required: Yes

Description:
Your own PRMuseum historical figure slug. Use exactly one of:
bernays
ivy-lee
lippmann
arthur-page

Wait for response: ON

2. ADD transfer_to_agent TO EVERY AGENT
---------------------------------------
Give each enabled agent transfer rules to every other enabled agent.
Examples:
- Bernays -> Ivy Lee, Walter Lippmann, Arthur W. Page
- Ivy Lee -> Bernays, Walter Lippmann, Arthur W. Page
- Lippmann -> Bernays, Ivy Lee, Arthur W. Page
- Arthur Page -> Bernays, Ivy Lee, Walter Lippmann

A useful condition is:
Transfer when the visitor asks to speak with [NAME], addresses a question directly
to [NAME], or an internal PRMuseum interface control message requests a transfer to [NAME].

3. ADD THIS BLOCK TO EACH AGENT PROMPT
--------------------------------------
Use the same block on every agent, replacing YOUR NAME and YOUR SLUG.

[PRMUSEUM MULTI-AGENT DISPLAY AND TRANSFER RULES]

You are YOUR NAME. Your PRMuseum interface slug is "YOUR SLUG".

The webpage has a client tool named setActiveAgent. It synchronizes the portrait,
name and suggested questions with the agent actually on the line.

Whenever you become active after an agent-to-agent transfer, BEFORE your first
substantive spoken response call setActiveAgent with your own slug. Do this even
when the transfer was requested naturally by the visitor rather than through the
webpage menu. Do not announce this technical action aloud.

If the visitor asks to speak with another available historical figure, or an
internal museum interface instruction tells you the visitor selected another figure:
1. Do not read or discuss the internal interface instruction aloud.
2. Use transfer_to_agent to transfer the ongoing conversation to that historical figure.
3. Do NOT call setActiveAgent with the destination slug yourself. The receiving agent
   must call setActiveAgent with its own slug after it actually becomes active.
4. Do not imitate or answer on behalf of the destination figure.

Available slugs:
Edward Bernays = bernays
Ivy Lee = ivy-lee
Walter Lippmann = lippmann
Arthur W. Page = arthur-page

YOUR NAME / YOUR SLUG values:
Edward Bernays / bernays
Ivy Lee / ivy-lee
Walter Lippmann / lippmann
Arthur W. Page / arthur-page

4. VERCEL BACKEND ENABLE / DISABLE
----------------------------------
Set this environment variable in Vercel:

PRMUSEUM_ENABLED_AGENTS=bernays,ivy-lee,lippmann,arthur-page

To temporarily hide/disable Lippmann:
PRMUSEUM_ENABLED_AGENTS=bernays,ivy-lee,arthur-page

To enable only Bernays and Page:
PRMUSEUM_ENABLED_AGENTS=bernays,arthur-page

After changing Vercel environment variables, redeploy.
An agent is shown only when it is in PRMUSEUM_ENABLED_AGENTS AND its matching
ELEVENLABS_AGENT_* ID exists.
