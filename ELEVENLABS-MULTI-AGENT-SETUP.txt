Living Archives v5.7 — Visitor Multi-Agent Setup
================================================

Visitor switching uses ElevenLabs native transfer_to_agent.
- Spoken transfer request -> current agent calls transfer_to_agent.
- Typed transfer request -> current agent calls transfer_to_agent.
- Portrait click -> website sends the same visible visitor request -> current
  agent calls transfer_to_agent.
- Portrait/name changes only after the transfer succeeds.

The separate AI Discussion feature is different: it uses two dedicated Dialogue
agent sessions and never uses transfer_to_agent for turn-taking.

See ELEVENLABS-TRANSFER-SETUP.txt and AI-DIALOGUE-SETUP.txt.
