PRMuseum Living Archives — ElevenLabs visitor transfer setup (v5.10)

Use the native Transfer to AI Agent / transfer_to_agent system tool on the FOUR NORMAL VISITOR AGENTS ONLY.
Do not use transfer_to_agent on the dedicated AI Discussion copies.

RECOMMENDED TRANSFER EXPERIENCE
- Transfer Message: LEAVE BLANK
- Delay before transfer: 0 ms
- Enable First Message: ON

Why: a blank transfer message avoids a handoff sentence being synthesized in the receiving agent's voice. Enabling the transferred agent's First Message removes dead air after the handoff and makes the new identity unmistakable.

FIRST MESSAGES
Edward Bernays: "Edward Bernays here. What would you like to discuss?"
Ivy Lee: "Ivy Lee here. What would you like to discuss?"
Walter Lippmann: "Walter Lippmann here. What would you like to discuss?"
Arthur W. Page: "Arthur Page here. What would you like to discuss?"

These messages should work both when the figure starts a fresh conversation and when they receive a transfer.

CLIENT EVENTS — ENABLE ON THE NORMAL VISITOR AGENTS
- audio
- user_transcript
- agent_response
- agent_tool_request
- agent_tool_response
- agent_response_complete

The site requires agent_tool_request and agent_tool_response to switch the portrait at the real native transfer boundary. The parent agent's client-event configuration is inherited during an agent transfer, but for consistency configure the same set on all four visitor agents.

TRANSFER TOOL DESCRIPTION
Transfer the visitor only when the MOST RECENT NEW visitor utterance received while you are the active agent explicitly asks to speak with, talk to, switch to, or be transferred to a DIFFERENT available historical figure.

A transfer request can be spoken, typed, or generated by the museum interface and should be treated identically.

Never transfer because of an older request preserved in conversation history. If an earlier request asked to speak with YOU, that request has already been fulfilled because you are now the active speaker.

Do not transfer merely because another figure is mentioned, discussed, quoted, compared, criticized, praised, or relevant. Never transfer based on another agent's First Message or handoff language.

DESTINATION CONDITION TEMPLATE
Transfer to [TARGET] ONLY when the MOST RECENT NEW visitor utterance, received while [CURRENT AGENT] is the active speaker, explicitly asks to speak with [TARGET], talk to [TARGET], switch to [TARGET], or be transferred to [TARGET].

Do not use older messages from before [CURRENT AGENT] became active as a transfer trigger. A prior request to speak with [CURRENT AGENT] is already fulfilled. Do not transfer merely because [TARGET] is mentioned or discussed.

PROMPT GUARD TO ADD TO EACH VISITOR AGENT
[AGENT TRANSFER SAFETY]
You are [YOUR NAME].
The full conversation history may contain a visitor request that caused a transfer to you. If an earlier message says the visitor wants to speak with you, that request is ALREADY FULFILLED because you are now the requested person. Never transfer away in response to that historical request.

Only use transfer_to_agent when the MOST RECENT NEW visitor utterance received while you are already the active speaker explicitly asks to speak with a DIFFERENT available historical figure. Never transfer based on another agent's message, your First Message, or an older visitor request.

UI destination hint, then confirms it against ElevenLabs' transfer_to_agent
