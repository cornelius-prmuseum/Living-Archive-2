LIVING ARCHIVES VISITOR AGENT SETUP — v5.6.2

NORMAL VISITOR AGENTS
Edward Bernays / Ivy Lee / Walter Lippmann / Arthur W. Page

Recommended ElevenLabs settings:

1. Transfer to AI Agent: OFF / REMOVE THE TOOL
   Living Archives now changes figures by ending the current ElevenLabs session
   and opening a new one. Do not configure transfer_to_agent for visitor switching.

2. First Message: LEAVE BLANK
   Living Archives sends the opening greeting itself for a fresh museum session.
   During a handoff it instead injects the recent conversation and prompts the
   incoming figure to continue naturally.

3. Security -> Overrides -> First message: NOT REQUIRED
   v5.6.2 no longer sends a First Message override. You may leave this disabled.

4. Remove these old client tools when convenient:
   - syncActiveAgent
   - setActiveAgent
   v5.6.2 still registers harmless compatibility handlers so an older agent
   configuration containing either tool will not crash the conversation.

5. Prompt cleanup
   Remove instructions requiring transfer_to_agent, syncActiveAgent, or
   setActiveAgent. The webpage now owns figure switching and portrait state.

6. Keep normal voice/persona/knowledge settings unchanged.

HOW HANDOFFS WORK
- Visitor clicks another historical figure.
- The click appears in the transcript as a normal visitor request.
- The current figure gives one brief handoff sentence.
- Living Archives waits until that spoken turn fully finishes.
- The current ElevenLabs session ends.
- A fresh session opens for the selected figure.
- Recent transcript context is injected silently.
- The incoming figure is prompted to continue naturally.
- The portrait changes only after the new session connects.

IMPORTANT
If a dashboard First Message is still configured, the agent may speak that greeting
before Living Archives sends its own opening/continuation prompt. Clear the First
Message on all four visitor agents for the intended behavior.
